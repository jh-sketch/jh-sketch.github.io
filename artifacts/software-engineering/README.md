
# Travlr Getaways

## Software Design and Engineering Enhancement

**Course:** CS 499 – Computer Science Capstone

**Original Project:** CS 465 – Full Stack Development I

### Project Overview

Travlr Getaways is a full-stack travel application developed using Node.js, Express, Angular, MongoDB, and Mongoose.

The application allows users to view travel packages and provides an administrative interface for managing trip information.

### Enhancement Overview

For my capstone, I improved the application's API error handling, reliability, and maintainability.

The enhancements include:

- Centralized API error handling
- Consistent JSON error responses
- Improved handling of missing travel packages
- Better organization of error-handling logic
- Testing of API routes and error conditions

### Technologies Used

- JavaScript
- Node.js and Express
- Angular
- MongoDB and Mongoose
- JWT Authentication
